# 色画用紙の在庫

大王製紙「再生色画用紙フレッシュカラー」4ツ切（100枚入り）の在庫を、先生たちで共有して管理するページです。

- **使い方**：公開ページのリンクを開くだけ。ログインやメールアドレスの入力はいりません。
- **できること**：使った枚数の記録（−10／−1）、補充（＋1袋）、棚卸し、発注リスト、月ごとの使用記録、押しまちがいの取り消し
- **しくみ**：画面は GitHub Pages（`index.html`）、データは Supabase のデータベースに保存しています。
- **注意**：リンクを知っている人はだれでも入力できます。リンクは校内だけで配ってください。

## ファイル
| ファイル | 内容 |
|---|---|
| `index.html` | 画面（これ1つで動きます） |
| `supabase/schema.sql` | データベースの形（参考） |
| `CLAUDE.md` | 引きつぎメモ（しくみと、直すときのルール。Claudeが作業の最初に読みます） |
